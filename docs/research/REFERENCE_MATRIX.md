## 2. 机制采纳与落地映射矩阵

我们对上述 19 个项目中的机制进行了严格的“去伪存真”过滤，在保持本项目单体轻量化的前提下进行落地：

```text
+-----------------------------------------------------------------------------------------------+
| 机制类别             | 灵感来源                  | 当前系统中的落地状态与代码落点                       |
+-----------------------------------------------------------------------------------------------+
| 1. 细粒度证据切片    | P15 RefChecker            | ✅ 已落地。所有实体、事件、事实均记录字符起止偏移量，  |
|    与防幻觉溯源      |                           |    前端滑出 EvidenceDrawer 精确回查上下文。          |
|-----------------------------------------------------------------------------------------------|
| 2. 事实时态演变与    | P13 Graphiti, P17 NeuroBook| ✅ 已落地。实现 FactVersion 与 StateChange，明确标明  |
|    有效区间判断      |                           |    某事实在“第几章生效、第几章失效、何时再次成立”。   |
|-----------------------------------------------------------------------------------------------|
| 3. 人物信息差与      | P11 Anima-RAG             | ✅ 已落地。ActorKnowledge 与 KnowledgeTransfer，     |
|    认知流动追踪      |                           |    记录“谁亲眼见证、谁听信谎言、谁尚不知情”。         |
|-----------------------------------------------------------------------------------------------|
| 4. 连续分窗与长篇    | P05 ViMax, P16 GraphRAG   | ✅ 已落地。长篇材料受 15万 Token 软上限约束，采用     |
|    保真切片          |                           |    “连续窗口切片 → 聚合”保真管道。                   |
|-----------------------------------------------------------------------------------------------|
| 5. 模块化单体与      | P19 SillyTavern           | ✅ 已落地。借鉴轻量单机优势，摒弃复杂微服务，采用     |
|    原生轻量化设计    |                           |    FastAPI + SQLite + React 前后端分离单机极简交付。 |
+-----------------------------------------------------------------------------------------------+
```

### 明确排除的过渡机制：
- ❌ **复杂分布式图数据库（Neo4j 集群等）**：排除。单书拆解规模下 SQLite + 内存索引性能与可靠性远胜外部图数据库。
- ❌ **全自主多智能体自组织通信（AutoGPT/Multi-Agent 混乱通信）**：排除。不可控且无法保证可复现性，改为确定性流水线 + 结构化插件。
