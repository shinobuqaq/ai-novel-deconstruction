## 总原则(评审任何产出前先过这三条)

1. **答案必须可定位、可计数、可抽查**:第几章第几段、几章一次、占比多少、间隔多少万字。形容词式结论(「节奏很好」「人物立体」)一律视为无效产出。**关键结论必须附原文摘句/上下文片段(带出处),让未读原著的用户可直接抽查采信;只给章节坐标不给原文的产出视为不完整**——用户是唯一质检员且不会去读原著,结论不自带证据,用户就无法「看到哪里不合适提出问题」。
2. **两个最终出口**:一切拆解最终要能结算进「倒推的最小开书包」(开新书第一天桌上摆什么)或「可复制套路库」(可迁移的结构参数与模板);对不上出口的分析再漂亮也是自嗨。
3. **工程出口验收**:凡声称服务写作 agent 的产出,必须能回答「哪个 agent、在管线哪一步、以什么文件格式吃掉它」(详见第七节)。

## 一、开书前决策(定卖点、定金手指、划禁区)

**这一步你在决策什么**:品类已定的前提下——这本书凭什么立住、爽点发动机是什么、哪些雷绝不能踩。品类是与读者的隐形契约,决定后面所有决策的边界;金手指不是一个点子而是一台要陪跑百万字的机器。大神读完一本书的开篇必须能回答「这本书凭什么是它火」——卖点一句话说不出来,后面拆得再细都是白拆。(「进哪条赛道/选哪个题材」属于跨书层决策,见 8.6。)

**1.1 本书兑现了品类的哪些「必给预期」?** ·核心·写手+编辑共识
- 问:本书所属品类读者的「必给预期」清单是什么(如系统流必须定期开奖、赘婿流必须打脸)?本书逐条对照:哪些兑现了、第几章以什么方式兑现;哪些改了、哪些没给,数据/口碑上付出了什么代价†?
- 为什么:新人最常见的死法是不知道自己违反了品类契约;欠核心预期不还的书,数据一定差。把「套路」从模糊经验变成可核对协议。
- 产出:品类必备元素检查表(元素/是否兑现/兑现章节/兑现方式),附各元素在本书的实现案例。
- **过渡方案**:清单本体最终由跨书交集构建(见 8.1),但第八节在单书拆解成熟前不启动——过渡期允许用**专家先验的品类必备元素清单**(LLM 知识+公开写作论)作对照基准,产出统一标注「先验清单,待跨书交集验证」;当 8.1 的 N≥3 交集清单建成时,先验清单即被取代,已有对照结论按新清单复核。
- 来源:原话「我想要去学习现有的网文,他们都是怎么写的,套路是什么」。

**1.2 本品类的雷点禁忌清单是什么?本书有没有擦边、擦边时怎么化解的?** ·核心·大神+编辑共识(与 1.1 成对:1.1 拆「必给什么」,本条拆「绝不能写什么」)
- 问:本品类读者公认的雷点/毒点清单是什么(降智/圣母/NTR/送人头/无意义虐主/机缘被夺不报复等)?本书有没有擦边段落?擦边时作者用什么手法化解(提前给读者预期管理/快速反转兑现/借角色之口吐槽消解)?踩雷的实际代价有多大†?
- 为什么:大神拆书既拆「必给什么」也拆「绝不能写什么」;而 AI 写作恰恰最容易无意识踩雷——LLM 为制造冲突常写出降智桥段。雷点清单是写作管线最高价值的**负向校验规则**来源。
- 产出:品类雷点枚举(先验+跨书归纳,与 1.1 清单同源维护,同样标注「先验/已验证」)+ 本书规避/化解案例(位置+手法+原文摘句)→ 作为写作管线的负向校验规则接入 7.1 映射表。
- 来源:专业补充(「套路是什么」的负面清单)。

**1.3 本书的差异化落在哪一层?** ·核心·写手+编辑共识
- 问:差异化落在题材外衣、金手指机制、叙事视角、情绪基调还是人物关系层?有没有动到品类核心预期?动了的话付出了什么代价?
- 为什么:只学交集会写成平庸缝合怪,而把差异化做在核心预期上(「我偏不打脸」)是另一种死法;成功书的创新几乎都在外衣层和机制层。这直接回答「我该在哪创新、哪不能动」。
- 产出:套路层(与品类一致)vs 创新层(本书独有)分层对照表 + 同品类多书「一句话卖点」对比表。
- 来源:引申(「套路是什么」的另一面:哪里可以不按套路)。

**1.4 核心卖点能否一句话概括、多快兑现?** ·核心·大神+写手+编辑共识
- 问:卖点能否压缩成一句读者前三章内自己就能复述出来的话(题材组合+情绪承诺,如诡秘=克苏鲁×蒸汽朋克×扮演成神)?卖点与金手指是一体还是分离?书名/简介/前三章各把这个承诺兑现到什么程度、第几章第几字第一次兑现?
- 为什么:卖点一句话是开书决策的第一行字,也是读者决定追不追、拿去安利别人的那句话;承诺兑现太晚读者就走了。拆成功书就是在收集被市场验证过的一句话及其兑现速度证据。
- 产出:卖点一句话卡 + 承诺-兑现追踪表(承诺内容→首次兑现位置→兑现方式)+ 同类书卖点对比。
- 来源:原话「金手指和核心卖点是什么」。

**1.5 金手指的完整机制规格是什么?限制条款怎么卡住战力膨胀?** ·核心·**四视角共识**
- 问:金手指的能力/触发使用条件/代价与限制/成长轨道/量产的爽点类型五要素各是什么?相对同期同类作品,差异化属于哪种(全新机制/旧机制新组合/旧机制新题材)?限制条款在全书被**真实触发**过几次、各在什么剧情节点、如何在机制层面卡住主角过早无敌?
- 为什么:金手指是整本书的发动机,战力膨胀的病根多半埋在这里——无限制的金手指三十万字后必然杀死悬念,而限制是否「真的咬人」必须数次数。写成机制规格书(而非卖点描述)后,它同时是写作 agent 的可执行规则和一致性校验器的规则来源。
- 产出:金手指规格卡(能力/条件/代价/成长轨道/爽点类型五段式)+ 限制触发事件表(位置/后果)+ 同期同类 2-3 本差异化对比。
- 来源:原话「金手指和核心卖点是什么」「战力膨胀严重」。

**1.6 金手指的升级阶梯与爽点生产方式是什么?** ·重要·大神+写手共识
- 问:全书几次质变、每次间隔多少万字、各绑定什么剧情事件(濒死/奇遇/顿悟)?与主角境界、剧情节点如何同步?有没有「旧能力新用法」的复用案例?它产出爽点的方式分哪几类(信息差装逼/越级碾压/积累变现/身份反差),主力是哪类?
- 为什么:金手指升级节奏是全书爽点大动脉的心跳,间隔太密战力崩、太疏读者腻;拆出主力爽点方向,开新书时才知道自己的金手指该往哪用。这是纯数据问题,系统比人肉阅读更适合回答。
- 产出:成长阶梯图(阶段×新增能力×对应章节×同步事件)+ 间隔字数统计 + 爽点方式分布(分卷)。
- 来源:引申(「金手指和核心卖点」的细化)。

## 二、设定构建(人物、世界观、大纲:写多少、写多深、先写哪个)

**这一步你在决策什么**:开书那天桌上要摆什么——人物写几个写多深、世界观预写到哪一圈、大纲写到什么颗粒度、哪些锁死哪些留给写作中生长。专业答案先说结论:不存在「先写完世界观再写人设」的线性顺序,真实顺序是「主角最小完整集先定死→反派和核心配角按功能配齐→世界观只预写开篇够用的最内圈+少数长线锚点」;但这个「够用」的边界在哪,必须靠拆书从成功作品实证。大神拆人物从不抄性格标签,拆的是功能分工与出场序;拆世界观从不抄设定集,拆的是揭示节奏与势力棋盘。

**2.1 开篇的人物标配阵容是多少?** ·核心·大神+写手+工程共识
- 问:前 3 / 10 / 30 章实际登场并**起作用**的具名人物各几个?每人首次出场时承担什么功能(给信息/给冲突/给资源/给情感/给对照)?平均隔几章引入一个新人?——直接验证「1 主角+2 配角+1 反派起步够不够」。
- 为什么:开篇人物是功能位不是户口本,答案藏在成书数据里,数一数头部书就有标准配置,不用凭空纠结。**注意:登场数是观察量,不等于开书前的预先设计量(作者可能预设很多但压着不放)——设计量需结合 2.11 的锁死/生长判定与 6.4 的最小开书包倒推得出,评审时不得把登场统计直接当设计量结论。**
- 产出:角色出场序表(顺序/章节/首场功能/后续戏份量级)+ 多书对比得出「开篇标配阵容」。
- 来源:原话「先只写一个主角和2个配角一个反派,还是往更多了写」。

**2.2 主角人设的最小完整集是什么、各在第几章立住?** ·核心·大神+写手+工程共识
- 问:主角的表层欲望(具体目标)与深层欲望(价值观)分别是什么、各在第几章通过什么事件确立?最小完整集(动机/欲望目标/性格反差/行为底线/金手指)各要素的交代节奏如何?两层欲望在哪些节点冲突并推动弧光转折?
- 为什么:表层欲望驱动情节、深层欲望驱动弧光,只有一层欲望的主角撑不过五十万字;人设不是填资料卡,是「读者通过哪几个事件认识主角」——拆出交代节奏,就知道开书前哪些必须想清楚、哪些可以后补。人设卡也是 agent 每章必注入的上下文(见 7.3)。
- 产出:主角动机双层卡 + 要素交代节奏表(要素→首次展示章节→展示事件)+ 弧光转折点时间轴;配角做轻量版。
- 来源:原话「我想知道别的作品的人物怎么设计的」。

**2.3 配角班子按什么功能编制?** ·核心·大神视角
- 问:常驻配角几个?每人的功能标签(工具人/情感锚点/搞笑担当/成长参照/信息口)?有没有功能重叠或功能空缺?
- 为什么:配角是按功能编制的班子不是按喜好养的宠物;功能分工矩阵直接回答开新书时配角班子的最小配置。
- 产出:配角功能分工矩阵(角色×功能×活跃卷)+ 重叠与空缺标注。
- 来源:原话「想知道别的作品的人物怎么设计的」。

**2.4 反派梯队怎么供给压力?反派有没有自己的事业?** ·核心·大神视角
- 问:反派是单体还是梯队?每层登场时与主角实力差多少、平均几万字消耗一个?最终 BOSS 从第几章开始铺垫?主要反派的动机是否独立于「跟主角过不去」、有没有自己的事业线?塑造最立体的反派用了什么手法(视角章/前史/理念冲突)?
- 为什么:反派是压力供应链,断供剧情就松、超供主角就死,梯队强度差和消耗速度是网文最需要量化的参数之一;反派有自己的事业,世界才像活的,冲突才有必然性。
- 产出:反派梯队表(层级/登场-退场位置/与主角实力比/铺垫起点)+ 反派动机卡(自身目标/结构性冲突原因/塑造手法)。
- 来源:原话「想知道别的作品的人物怎么设计的」+ 专业补充(反派事业线)。

**2.5 重要角色的记忆点怎么设计和强化?** ·重要·大神视角
- 问:每个重要角色的记忆点(口头禅/外貌符号/行为模式/反差)是什么?首次亮出在第几章?后文以什么频率重复强化?
- 为什么:百万字里读者记得住的角色不超过十个,记忆点是角色的商标,其设计和重复频率完全可以量化后模仿。
- 产出:角色记忆点清单(角色/记忆点/首现位置/强化频率)。
- 来源:引申(「人物怎么设计」的细化)。

**2.6 开书前必须定死哪些设定?世界观预写量的边界在哪?** ·核心·**四视角共识**
- 问:前 30 章每章新增多少设定量、通过什么载体带出?哪些设定项(力量体系/地理/势力/规则)被后文高频引用、哪些写了从未用到?核心设定各自的首次提及/部分揭示/完整揭示在第几卷第几章、开篇露出约占全貌百分之多少?据此反推:「开书前必须锁定」与「可边写边补」两列清单各是什么?
- 为什么:「先写世界观还是先写人设、写多深」的真正答案是——世界观按需释放,预写量 = 前 30 章会用到的 + 长线锚点;未被引用的设定在 agent 管线里是纯上下文噪音,而必须先定死的项中途改动就是全书一致性崩坏。用引用依赖数据回答,而非经验之谈,能终结「写多深」的焦虑。
- 产出:世界观信息释放曲线 + 设定项引用计数/依赖图 + 设定揭示时间表(首提×部分×完整位置)+「必锁定/可延迟」两列清单 + 开篇露出比。
- 来源:原话「先写世界观还是先写人设还是先写剧情大纲,写的话要多深入」「写到后期世界观前后矛盾」。

**2.7 设定揭示靠什么剧情载体,才不写成说明书?** ·核心·大神+写手共识
- 问:每次重大设定揭示通过什么载体完成(主角亲历/角色转述/文献道具/反派得意忘形)?揭示时机与主角当时的求知动机怎么绑定?本书有没有说明书式灌输的段落?
- 为什么:同样的设定,灌输是毒点、揭示是爽点,差别全在载体和时机——这是 AI 写作最容易翻车的地方,必须拆出正面范例。
- 产出:揭示手法案例库(设定项/载体类型/当时主角动机/原文位置)。
- 来源:原话「想知道别人怎么设计世界观」引申。

**2.8 世界级终极悬念怎么分段兑现?** ·核心·大神视角
- 问:这个世界的终极大谜团是什么?被切成几段揭示、每段间隔多少字?每次揭示是否同时抛出更大的新谜团?
- 为什么:顶级长篇都靠一个够深的世界级谜团吊全程;拆它的分段兑现结构,等于拿到长线悬念的分期付款方案——这是开书前必须预谋的长线锚点之一。
- 产出:终极悬念分段揭示图(段×位置×揭示内容×同时新抛的谜团)。
- 来源:原话「怎么设计世界观」+「钩子怎么设计的」引申。

**2.9 势力棋盘:圈层怎么详略、关系怎么重组、主角怎么爬?** ·核心·**四视角共识**
- 问:主要势力几方,各自的目标/核心资源/行事风格?圈层结构(村→城→国→大陆→位面)开篇详写到第几层、外层留什么程度的模糊轮廓?开局关系格局(敌对/同盟/依附/中立/互不知情)是什么?隐藏势力第几章揭示、揭示时是否改写已知关系?关系在哪几卷重组、由什么事件触发?主角在棋盘上的位置怎么升级(棋子→玩家→执棋人)?
- 为什么:势力不是背景板,是冲突发生器——各方目标的互斥结构决定剧情能自动生长出多少冲突;静态势力图谁都会画,值钱的是动态:关系重组就是卷级剧情的骨架,主角位置爬升就是权力爽感的来源。大神都是内圈写实、外圈写虚,虚实边界要从成书里量出来。
- 产出:势力档案表 + 圈层详略图(每层:开篇详略程度/首次详写位置)+ 带时间维度的关系矩阵 + 分卷关系快照序列 + 主角棋盘位置轨迹。
- 来源:原话「我想知道别的作品怎么设计世界观、势力、不同势力的关系等内容的」。

**2.10 力量体系的阶梯是否一次设计够长?硬规则与代价是什么?** ·核心·大神+写手+工程共识
- 问:力量体系分几级、每级的标志能力和获取条件?阶梯总长度是否在开书时就设计到足够支撑百万字?硬规则与代价(失控风险/资源稀缺/寿命/禁忌)是什么?
- 为什么:战力膨胀不是写崩的,是开书时阶梯就不够长、升级又没有节流阀;规则与代价条款是后期张力和一致性校验的共同来源(执行情况的实测见 5.1/5.2)。
- 产出:力量体系阶梯表(级×标志能力×获取条件)+ 规则-代价条款清单。
- 来源:原话「战力膨胀严重」「怎么设计世界观」。

**2.11 哪些设定是开书前锁死的、哪些是边写边长出来的?** ·核心·大神+写手共识
- 问:从成书倒推,哪些设定/剧情节点必然是开书前锁死的(证据:前期闲笔与后期跨百万字的精确呼应)?哪些明显是写作中期才生长出来的(证据:前后微调/刻意模糊/前文零铺垫)?后补设定用了什么软着陆手法(借新地图引入/借配角之口追认/模糊旧表述)?
- 为什么:没人能拿到大神的原始大纲,但成书里藏着指纹——这是回答「开书前大纲和设定写多细」的唯一实证途径,也是拆书系统独有、写作教程给不了的价值;大神也不是全想好才动笔,拆出锁死层与生长层的边界比任何写作课都实在。
- 产出:预谋/即兴判定清单(节点→判定依据)+ 后补设定案例库(软着陆手法)+ 设定分层清单(锁死层/生长层/模糊带)。
- 来源:原话「写的话要多深入」「前后矛盾」。

**2.12 大纲的颗粒度:卷级参数与主线节点密度是多少?** ·核心·大神+写手+工程共识
- 问:全书几卷?每卷字数、一句话核心任务(引入/立足/扩张/翻盘/决战)、核心对手、卷末状态各是什么?卷任务序列呈什么升级逻辑?主线平均多少万字出现一个不可逆节点(拿到关键物/身份揭露/势力覆灭)?
- 为什么:卷是百万字的战略单位,大纲实际是按卷写的——卷级里程碑写死、章级留给日更即兴;拿到成功书的卷任务序列和节点密度,分卷大纲就有了模板骨架,也是大纲 agent 的硬参数。
- 产出:分卷任务表(卷号/字数/任务/对手/卷末状态)+ 卷结构参数分布(多书)+ 主线节点时间轴与间隔统计。
- 来源:原话「剧情大纲」「剧情节奏怎么设计」。

## 三、开篇(黄金三章到商业卡点:生死线)

**这一步你在决策什么**:读者第一眼看什么、信息按什么顺序装载、第一口爽多快给、把哪个高潮押在商业卡点(付费墙/完读率节点)前。签约、推荐、留存全看这里;开篇是全书的压缩饼干,拆懂开篇等于拿到作者的优先级排序——他认为什么信息最不能等、什么设定可以压着不讲。大神的第一遍精读只读前三章到前三万字,逐段标记:这一段给读者什么信息、什么情绪、为什么是这个顺序。

**3.1 开场第一幕是什么类型?主角怎么登场?** ·核心·大神+写手共识
- 问:开场场景属于哪种类型(冲突进行时/悬念异象/日常被打破/穿越降临即打脸)?主角第几段出场、出场时正在做什么、面对什么麻烦?第一句话/第一段承担什么功能?本品类头部书的开局类型分布是什么?
- 为什么:开场前 500 字是弃书率最高的地方,大神几乎从不写平静日常开场;把头部书开局做类型学统计,新人可以直接按品类选被验证过的开局式。
- 产出:首章开场卡(场景类型/主角出场段落/初始麻烦)+ 按品类的开局类型统计 + 每类型第一段原文案例。
- 来源:原话「怎么写能吸引读者注意力」。

**3.2 前三章逐章完成了什么任务、信息按什么顺序装载?** ·核心·**四视角共识**
- 问:第 1/2/3 章各完成什么任务(代入身份/展示困境/亮金手指/给第一口爽/留钩)?信息模块(主角困境/性格/金手指/世界观规则/威胁/短期目标)各自首次出现在第几章第几段、各占多少字?金手指在第几章第几段亮相?
- 为什么:黄金三章本质是信息装载顺序题——什么先说、什么后说、每样说多少,是新人最容易做错的地方;它也是网文最标准化、共识度最高的结构,逐章逐段拆任务直接得到可套用施工图,agent 生成后可逐项核对。
- 产出:黄金三章任务拆解模板(章×段落任务序列×关键事件字数定位)+ 信息装载时间轴,多书对比出标准节奏区间。
- 来源:原话「怎么写能吸引读者注意力」「要写哪些设定…写的话要多深入」。

**3.3 第一个爽点在哪、铺垫距离多少字?** ·核心·大神+写手+编辑共识
- 问:第一个明确的情绪释放点(爽点/燃点)出现在第几章第几段、开头多少字处?它兑现的是前文哪一处埋下的期待、铺垫距离多少字?
- 为什么:三章内没有一次情绪支付读者就走了;「首爽位置+铺垫距离」在成功书里是收敛的数值,是开篇最实用的节奏参数、最硬的可学参数。
- 产出:首爽定位卡(位置/类型/铺垫来源/铺垫距离字数)+ 跨书首爽字数统计对比。
- 来源:原话「怎么写能吸引读者注意力」。

**3.4 前三章的章末钩是什么、多快兑现?** ·核心·大神视角
- 问:前三章每章结尾各用什么钩子(危机悬置/新信息/期待确立/反转)?钩子指向的问题分别在第几章被回应、赊账距离多少?
- 为什么:开篇章末钩是追读率的直接杠杆,而且开篇的钩必须快兑现——读者信任还没建立,不能赊账太久(全书章末钩节律见 4.9)。
- 产出:前三章章末钩清单(类型/指向问题/兑现位置/赊账距离)。
- 来源:原话「钩子怎么设计的」。

**3.5 代入感靠什么安装?欲望-障碍-赌注配齐了吗?** ·重要·大神视角
- 问:主角的欲望-障碍-赌注三件套在前三章是否配齐、各在哪一段明确?读者代入感靠什么建立(惨/憋屈/野心/责任)?
- 为什么:读者留下不是因为世界观,是因为想看「这个人接下来怎么办」;三件套不齐的开篇必扑,拆它就是拆代入感的安装步骤。
- 产出:代入感安装清单(欲望/障碍/赌注/同情点的定位+原文引句)。
- 来源:专业补充(大神视角)。

**3.6 前三章交代了什么、刻意悬置了什么?** ·重要·大神+写手共识
- 问:前三章交代了哪些设定、刻意悬置了哪些(身世/金手指来历/大反派)?悬置项分别在多少字后揭晓?哪些重要设定被刻意延迟到什么时候?
- 为什么:新人前三章最容易犯的错是设定倾泻,大神的前三章是「给最少的信息+留最勾人的空白」;交代/悬置对照就是信息配给的标尺,也直接矫正 AI 写作的说明书病(与 2.6 联动:前三章用不到的就不必预写细节)。
- 产出:前三章「已交代/悬置」对照表 + 悬置项揭晓距离统计 + 延迟揭示清单。
- 来源:引申(「吸引读者注意力」+「写多深入」的交叉)。

**3.7 商业卡点前后的结构怎么设计?(按商业模式分支)** ·重要·写手+编辑共识 ·†
- 问:**先按样本书元数据分支**。付费文(起点系):上架/入V节点(通常 20-50 章)前最后 10 章如何层层堆压到悬念最高点?免费部分最后堆出的高潮是什么、第一个付费章节挂了什么规格的爆发与钩子让读者愿意掏钱?免费文(番茄/七猫系):前几万字完读率关键节点(如前 1 万/3 万字)前后的强钩与爽点怎么排布?章末钩密度与广告解锁节奏怎么配合、比付费文密多少?
- 为什么:付费文的首订与免费文的完读率是两条完全不同的商业生死线,对应两套节奏参数体系,混用会学错;成功书都把一个卷级高潮精确卡在自己模式的卡点前——这是强套路、强可复制,但新人完全不知道它存在。用户尚未定平台,两套都要拆。
- 产出:按模式分支的卡点前后逐章功能拆解(高潮爬升曲线+卡点后首章钩子类型),跨书对比仅在同商业模式内进行(见 8.2)。**†降级**:无付费转化/完读数据时,输出结构侧拆解与设计意图推断,「是否有效换来首订/完读」的效果结论标注「待读者数据验证」。
- 来源:专业补充(由原话「写得好可能也能当做一门副业」的商业目的引申)。

## 四、连载运营(日更循环:单元、节奏、爽点、钩子、主支线)

**这一步你在决策什么**:每天在大纲留白处即兴,但即兴必须有容器——当前事件单元推进到哪个阶段、本章写什么章型、爽点怎么排、钩子怎么收、支线什么时候插进来换口气。大神拆节奏不靠读感,是逐章打标签画曲线;拆结构就是找作者的分层方案和可复用的循环单元——这才是量产的秘密,也是最适合直接喂给写作 agent 的量化层。

**4.1 卷内有没有可复用的事件单元模板?** ·核心·大神+写手+工程共识
- 问:是否存在重复使用的事件单元(如:接触新麻烦→初步受挫→收集筹码→翻盘→结算收获→埋下一单元引子)?单元平均几章、铺垫-升级-爆发-余韵各占几章?全书复用了多少次、每次变体在哪?单元之间怎么衔接?
- 为什么:循环单元是网文量产的核心机密——读者要的不是新结构而是新内容旧节奏;找到这个模板,日更即兴就知道当前事件该写几章、写到哪个阶段,AI 写作就有了可执行的循环体。
- 产出:事件单元结构模板(阶段拆解+长度统计)+ 全书单元实例清单(位置/时长/变体点)+ 衔接方式清单。
- 来源:原话「套路是什么」「剧情节奏怎么设计」。

**4.2 卷末大高潮的收束链怎么运作?** ·核心·大神+写手共识
- 问:卷末高潮前多少章开始收线、动用了本卷哪几条伏笔/支线?高潮本身持续几章、爽感分几波推进(先小胜→受挫→翻盘→碾压)?全书大高潮几个、间隔多少万字?高潮后的「结算+过渡」平均几章、都干什么(发奖励/收人心/换地图)?
- 为什么:卷末高潮是一卷所有铺垫的总兑现,结构高度模式化;大高潮间隔与蓄力长度是长篇的呼吸频率,结算段长度更是新人完全没概念的参数。
- 产出:卷末高潮解剖图(收线起点→伏笔调用清单→波次结构→持续章数)+ 高潮分布图(位置/间隔/蓄力起点/结算段时长与内容)。
- 来源:引申(「剧情节奏怎么设计」的卷级落地)。

**4.3 卷与卷怎么衔接?换地图怎么不断崖?** ·重要·**四视角共识** ·†
- 问:上一卷结尾留了什么钩进入下一卷?大高潮结束后几章内抛出新钩、用什么手法(新地图/更强敌人/身世新线索/金手指异动)?新卷开头几章内完成「新舞台+新对手+新目标」刷新?换地图时机与主角实力、旧地图矛盾清算的同步关系?新图首个爽点来得多快?
- 为什么:卷末换地图是后台数据里典型的追读断崖——旧期待已结清、新期待未建立,读者「先放放」就再也不回来;换图做好是续命手术,做差是抛弃读者资产。
- 产出:卷间衔接案例卡(卷末钩/新卷三件套刷新位置)+ 换图衔接账本(旧线收束章号/新钩建立章号/间隔/新图首爽位置)+ 地图扩张时间轴。**†降级**:无追读数据时,衔接账本照常从文本产出,并把「新钩建立间隔过长/新图首爽过晚」的换图段列为候选断崖风险点,标注「待读者数据验证」。
- 来源:引申(「剧情节奏」的具体化)+ 专业补充(换图断崖)。

**4.4 主线与支线的配比、编排与回勾规律是什么?** ·核心·**四视角共识**
- 问:主线一句话是什么?支线几条、各属什么类型(感情/势力经营/复仇/解谜)?以章为单位,主线:支线:混合的比例是多少、随进度怎么变?支线通常插在弧的什么位置、连续占几章?每条支线用什么方式回勾主线(人物反哺/道具伏笔/势力铺垫)、离题距离多远?最长的「主线零推进区间」多少章、靠什么补偿(支线爽点/人物戏/日常调剂)?有没有始终没回勾的纯注水支线?
- 为什么:主支线分配是配比问题不是原则问题,新人不是主线太赶就是支线注水;「主线拖沓」必须变成可判定指标(连续 N 章无推进、无爽点补偿),成功书的容忍上限就是写作红线;支线的合法性来自回勾,「位置+时长+回勾方式」三元组是 agent 可执行的编排规则。
- 产出:逐章主/支线标注序列 + 分卷配比曲线 + 支线插入位置/时长/回勾方式统计 + 最长无推进区间及补偿手段清单。
- 来源:原话「主线与支线的分配」。

**4.5 爽点类型怎么配比与轮换?重复时怎么对抗边际递减?** ·核心·大神+编辑共识
- 问:逐个标注爽点类型(装逼打脸/越级碾压/升级突破/身份揭晓/收获结算/情感兑现/复仇兑现/解谜),各占比多少?主力类型与品类是否匹配?同一类型连用时怎么变花样?重复出现时靠什么对抗递减——对象升级/规模升级/形式变体/类型轮换,升级步长多少(每次强 20-30% 还是翻倍)?
- 为什么:每个品类有主力爽点配方,配比错了读者觉得「不对味」;爽点会边际递减,类型轮换是抗疲劳核心手段,升级步长失控就是战力膨胀的情绪面——这些拆出来才能避免 AI 一招用到死。
- 产出:逐爽点标注表(位置/类型/强度/对象)+ 类型占比图 + 主力类型变体案例 + 同类型爽点历次强度升级阶梯图。
- 来源:原话「怎么写能吸引读者注意力」「战力膨胀严重」引申。

**4.6 爽点密度曲线什么形状、分阶段怎么变?** ·核心·**四视角共识**
- 问:平均几章(每万字)一个小爽点、多少字一个中高潮、大高潮压在哪?开篇卷/中期卷/后期卷的密度变化规律是什么(开篇密防流失、中期疏养期待)?密度低谷段持续多久、用什么兜底?能否压缩成一组可配置的节奏约束参数(如「每 3-5 章一个小兑现、每 30-40 章一个大高潮」)?
- 为什么:「节奏好」在数据上就是密度曲线形状好;而大神的密度是**变化**的,这个变化规律才是真功夫;做成命名参数后,节奏控制器可在大纲层直接校验——这是「节奏」从形容词变成工程量的关键。
- 产出:逐章爽点标注 + 分卷密度曲线(小/中/大三级,多书叠加找公共区间)+ 分阶段(开篇/中期/后期)参数对比表 + 命名节奏约束参数。
- 来源:原话「剧情节奏怎么设计」「怎么写能持续吸引读者注意力」。

**4.7 压抑-释放的间距与「憋屈上限」是多少?** ·核心·大神+编辑共识 ·†
- 问:最长的一次压抑段(主角吃瘪/蓄力到翻盘)持续几章?每个大爽点前铺垫多少字、压抑强度与释放强度配比如何?翻盘时靠什么放大爽感(当众/加倍/连环)?有没有压过头导致追读下滑的段落?全书压抑-释放平均间距?
- 为什么:压得越久爽得越狠,但压抑期本身是弃书高危区;「最大安全压抑时长」是最值钱的经验参数——新人不压不爽、压久必死,全靠这个数,只能从成功书里量出来。
- 产出:压抑-释放配对表(起止/时长/压抑手段/翻盘手法/放大技巧)+ 铺垫时长分布统计。**†降级**:「压过头导致追读下滑」无追读数据时,输出压抑段时长排行,把显著超出多书常态区间的段落列为「疑似压过头」候选风险点,标注「待读者数据验证」。
- 来源:原话「怎么写能吸引读者注意力」。

**4.8 张弛怎么排班?低谷章靠什么撑住追读?** ·重要·大神+写手共识
- 问:高强度冲突章之后接什么章型(结算/日常/感情/新线铺设)?「弛」段平均连续几章、同时承担哪些功能(结算/养情感/埋新线)?两个高潮间的低谷章用什么手法维持追读(小悬念接力/关系线推进/幽默调剂/新信息投放)?低谷期最长敢拉几章?
- 为什么:张弛交替不是玄学是排班表,弛段不是废戏要同时干三件事;弃书大多发生在低谷章而非高潮章,大神的功力恰恰在「没大事发生时读者也不走」。
- 产出:章节张/弛序列图 + 弛段功能统计 + 低谷章手法清单(附原文案例)+ 低谷期长度统计。
- 来源:原话「剧情节奏怎么设计」「怎么写能持续吸引读者注意力」。

**4.9 章末钩的类型配比与强弱节律是什么?** ·核心·**四视角共识**
- 问:逐章(或抽样 50+ 章)标注章末钩类型(危机悬置/新信息抛出/期待兑现前置/反转/情绪定格/无钩),各占比多少?连续强钩几章后放一章缓钩?连续使用同类钩的上限?弧内哪个阶段偏好哪类钩?无钩章什么条件下敢不设、靠什么维持追读?
- 为什么:章末钩是每天留住读者的最后一句话、追读率最直接的杠杆,编辑改稿第一刀几乎都砍在章末;类型配比、强弱节律和「敢不设钩」的条件是纯凭感觉最学不会的部分,拆成类型枚举+使用约束后 agent 的钩子选择才有依据。
- 产出:章末钩类型枚举表 + 逐章标注统计(占比/轮换/强弱交替模式)+ 无钩章场景分析 + 每类型 3 个原文实例(带出处)。
- 来源:原话「钩子怎么设计的」。

**4.10 悬念账本:埋设/兑现/存量怎么管理?** ·核心·大神+编辑共识
- 问:全书量级前十的悬念各自的埋设章、兑现章、跨度?短(几章)/中(一卷)/长(跨卷)三档悬念的数量配比?任意时刻同时在账的悬念保持几个?每兑现一个大悬念后隔多少章补充同量级新悬念?有没有悬念真空期、真空期靠什么撑?
- 为什么:悬念要分账期组合投放——短悬念维持日更粘性,长悬念撑起追更信仰;悬念存量清零的瞬间就是弃书高峰(很多书大高潮后崩盘就是这个原因),新账补充节奏是完本作者才懂的续命术。
- 产出:悬念账本总表(悬念/埋设/兑现/跨度/档位)+ 悬念存量随章节曲线。
- 来源:原话「钩子怎么设计的」「怎么写能吸引读者注意力」。

**4.11 悬念兑现的质量:哪些超预期、哪些拉胯?** ·重要·大神视角
- 问:哪些悬念兑现时超出读者预期、靠什么(答案反转/答案加码/时机提前)?有没有兑现拉胯或烂尾的悬念?
- 为什么:兑现质量决定作者信用,信用决定读者肯不肯接新悬念;正反案例都要拆,烂账的教训同样值钱。
- 产出:兑现质量案例集(超预期手法/拉胯原因对照)。
- 来源:专业补充(大神视角)。

**4.12 单章内部的微结构模板是什么?** ·核心·**四视角共识**
- 问:一章 2000-4000 字内部:承接上章钩子/推进剧情/小冲突或小爽点/埋点/收尾新钩各占什么比例?几个场景、是否切视角、切换粒度多大?对话/动作/叙述/心理的字数配比?不同章型(推进章/爆发章/过渡章/信息章)的配比差异?
- 为什么:章是读者的日更消费单位、连载的最小商业单元、也是写作 agent 的最小生产单元;把章拆成标准工序,即兴就有了容器——这是能直接喂给 agent 的最细粒度模板,也避免 LLM 默认文风(大段叙述、少对话)与网文阅读习惯冲突。
- 产出:章型分类 + 各章型内部结构模板(段落功能序列+比例区间)+ 统计参数(字数/场景数/切换粒度/四类文字配比)——可直接作为 agent 单章生成规格(见 7.1)。
- 来源:引申(「剧情节奏」在章尺度的落地+「用 agent 系统性的来写作」的直接输入)。

**4.13 爽点场景的内部节拍怎么写?** ·重要·工程视角
- 问:打脸/升级/夺宝/装逼各类爽点场景的内部节拍(压抑铺垫→反转爆发→旁观者反应→余韵)各占多少字?旁观者反应(配角惊叹/敌人懊悔)在爽感中的配比多重?
- 为什么:agent 写崩爽点的典型原因是缺「铺垫压强」和「旁观者反应」两个环节;做成场景级节拍模板后可作为单章生成的场景指令。
- 产出:爽点场景节拍模板(分类型)+ 环节字数配比统计 + 原文实例。
- 来源:引申(「怎么写能吸引读者注意力」的场景级落地)。

**4.14 视角纪律与信息差怎么打?** ·重要·大神视角
- 问:视角策略是什么(单一第三人称限知/多视角轮换)?非主角视角章占比、通常干什么(展示反派/铺垫危机/衬托主角)?信息差三形态——读者>角色(捏汗)、角色>读者(揭晓惊艳)、角色A>角色B(装逼打脸)——各自的使用场景和频率,本书最依赖哪种?
- 为什么:视角纪律决定信息差工具箱的大小,信息差是悬念和爽点共同的底层机关(诡秘「读者知道克莱恩是愚者」就是一台全书运转的信息差发动机)。
- 产出:视角分布统计 + 非主角视角章功能清单 + 信息差案例库(形态/场景/制造的情绪)+ 频率统计。
- 来源:专业补充(「钩子」「吸引注意力」的底层机制)。

**4.15 名场面与高潮场面的写法工艺是什么?** ·重要·大神视角
- 问:全书公认的名场面有哪几个,写法共性(蓄力多长/视角怎么切/金句落在哪/收尾定格在哪一拍)?大战/高潮场面平均多少字、用什么结构组织(多方视角切换/倒计时/阶段递进)?文戏高潮与武戏高潮的写法差异?
- 为什么:名场面是一本书的记忆商标和传播素材,它不是灵感是工艺——蓄力-引爆-定格的节拍完全可以拆解复用;高潮场面写短了泄气、写长了注水,实测规格直接可用。
- 产出:名场面解剖卡(蓄力起点/引爆结构/金句位置/定格方式)+ 高潮场面规格表(类型/平均字数/组织结构)。
- 来源:专业补充(大神视角)。

**4.16 感情线的剂量与摆放位置?** ·加分·大神视角
- 问:感情线(若有)占全书篇幅比例多少?推进节点(相识/误会/靠近/确认)与主线大事件怎么交错?感情戏通常摆在什么节奏位置(大战后/整备期)?
- 为什么:感情线既是节奏调剂器又是毒点雷区,剂量与摆放位置是纯经验参数,拆成功书是最安全的学法。
- 产出:感情线推进时间轴 + 与主线大事件的交错图。
- 来源:专业补充。

**4.17 文风的量化参数是什么?** ·加分·大神+工程共识
- 问:平均句长段长、对话与叙述比、描写密度如何?幽默等情绪调剂的手段和密度?这些参数与题材气质怎么匹配(诡秘的克制阴郁 vs 庆余年的机锋幽默)?
- 为什么:文风参数是 AI 仿写的直接输入之一——但注意文笔的主要可消费形态是范文片段库而非参数(见 7.6),此处只拆可量化的部分。
- 产出:文风量化参数表 + 风格-题材匹配说明。
- 来源:专业补充。

## 五、长线管理(百万字不崩:三本账)

**这一步你在决策什么**:记什么账、什么时候升维、支线关不关、角色退不退。百万字级作品的三大死法——设定前后矛盾(吃书)、战力膨胀失控、支线烂尾——全部是长线账本问题,这是用户最明确的恐惧,也是长篇与短篇的本质区别:短篇拼灵感,长篇拼账本。人类作者靠模糊记忆,agent 管线必须靠显式账本+校验规则;拆书系统的独特优势是能从成书把这些隐形账本整个重建出来。

**5.1 战力曲线全景与防膨胀手法是什么?** ·核心·**四视角共识** ·†
- 问:主角平均多少万字升一级、前后期变化规律?大境界突破前的压制期(被更强者压着打)持续多久?主角与当前对手的战力差随章节的曲线什么形状?「越级挑战」的常见幅度是几级、靠什么合法越级(金手指爆发/道具/外援)?写到后期作者用什么手段避免无敌化(新力量维度/更高圈层势力/规则型对手/换赛道/目标重置),有没有膨胀导致的口碑滑坡点?
- 为什么:升级间隔是这类书的心跳,间隔失控(太快膨胀/太慢憋闷)是最常见的崩书原因;把等级体系编码成偏序后,校验器可以判定「这一战的结果是否超纲」,越级幅度统计给 agent 一个「能赢但不崩」的操作空间。
- 产出:战力曲线图(字数轴×境界轴,多书叠加)+ 主角-对手战力差曲线 + 越级幅度/手段统计 + 防无敌手法清单(手法→启用时机→原文案例)。**†降级**:「口碑滑坡点」无书评/追读数据时,以战力曲线异常段(升级骤密/战力差长期归零)作候选滑坡点,标注「待读者数据验证」;曲线本体不受影响。
- 来源:原话「怎么写不会导致写到后期……战力膨胀严重」。

**5.2 规则与代价被真实执行过吗?硬软约束怎么区分?** ·核心·大神+工程共识
- 问:力量体系的硬规则与代价在剧情里被真实执行过几次?有没有为主角破例的时刻、作者怎么圆的?哪些规则被作者当作从不违反的硬约束、哪些是可软处理的弹性设定?能否输出一张「一致性校验规则表」?
- 为什么:规则被执行才是规则,被破例才见作者的圆谎功力(诡秘的失控设定立得住,是因为真死过人);区分硬/软约束能防止校验器过度报警扼杀剧情灵活性,校验规则也不必全靠人工编写。
- 产出:规则-代价执行记录表(规则/执行案例/破例案例/圆谎手法)+ 校验规则表(条款/硬软分级/全书遵守记录)。
- 来源:原话「前后矛盾」「战力膨胀」引申。

**5.3 长线伏笔账本:怎么埋、怎么保温、怎么引爆?** ·核心·大神+写手+工程共识
- 问:埋设距离超过 50 万字的伏笔有几条?每条的埋点伪装手法(闲笔/物品/预言/玩笑)、中途补提位置与手法(隔多少章重提一次才不显刻意)、回收时的引爆方式与「这早就埋了」的提醒手法?明悬念与暗伏笔的比例?伏笔悬置期分布——隔多少章回收算正常、同时悬而未决的伏笔数量上限大约是多少?
- 为什么:长线伏笔是「作者早就想好了」的震撼感来源,也是最需要开书前预谋的部分;长账不付利息读者就忘了或不信了,保温频率和手法纯靠经验、必须实测;悬置期分布和并发上限决定 agent 何时触发「回收提醒」。
- 产出:伏笔账本三列表(埋点/补提点/回收点,各标字数位置与手法)+ 悬置期分布图 + 并发未回收数量随章曲线 + 明暗比例与伪装/回收提示手法清单 + 账本 schema(见 7.1)。
- 来源:原话「前后矛盾」+ V0-B6「伏笔怎么埋、隔多远回收」。

**5.4 吃书实证:哪类设定最容易写崩、作者怎么圆?** ·核心·写手+工程共识
- 问:本书有哪些前后矛盾的设定(战力/规则/时间线/知情面)?哪类事实最容易被作者自己打破(数值类/绝对化表述类/时间类/「谁知道什么秘密」的知情面)?作者靠什么手法圆回来(模糊化追认/借角色之口修正)?事实状态账本应追踪哪些可判定事实(生死/位置/持有物/关系/能力等级/知情面)?
- 为什么:防崩的最好教材是崩的现场——连头部书都吃书;拆出「高危设定类型」排行,开书写设定时就知道哪些话不能说死(不写绝对数值、不说「唯一」「不可能」),校验器也有了盯防优先级。
- 产出:吃书案例库(矛盾点前后原文对照)+ 易崩事实类型排行 + 圆场手法清单 + 事实状态 schema 字段清单。
- 来源:原话「怎么写不会导致写到后期世界观前后矛盾」。

**5.5 支线的生命周期与烂尾率是多少?** ·重要·写手视角
- 问:支线平均活跃几章、挂起后隔多久唤醒、用什么方式唤醒(角色重现/伏笔联动)?全书多少比例的支线最终烂尾(开了没收)?可烂与不可烂的支线各有什么特征?
- 为什么:支线烂尾是长篇口碑崩塌的慢性病;拆出挂起-唤醒节律和头部书的实际烂尾率,既有管理方法也有心理预期(原来大神也烂尾 X%,哪些能烂哪些不能)。
- 产出:支线登记簿(开启/挂起/唤醒/闭合的字数位置)+ 烂尾率统计 + 可烂/不可烂特征区分。
- 来源:引申(「主线与支线的分配」的长线维度)。

**5.6 角色阵容怎么扩张、旧角色怎么退场?** ·重要·大神+写手+工程共识 ·†
- 问:每卷新增几个具名角色?第 1/50/200/500 章时累计命名人物数与活跃(近 50 章出场)人物数各是多少?不再有用的角色如何退场(死亡/离队/淡出/定期回访)?有没有被作者遗忘的角色、哪些处理引发读者不满(人气配角消失)?
- 为什么:长篇角色只进不出必然失控,是设定矛盾的温床;活跃实体数还决定 agent 检索库和每章上下文包的大小上限,超基线就该触发退场/归档机制——这也是「往更多了写」的长线后果。
- 产出:角色阵容曲线(总量/活跃量两条线)+ 分位数基线表 + 退场手法清单(方式/位置/是否回访)。**†降级**:「读者不满」无本章说/书评数据时,以结构信号(有戏份的配角长期未出场且无退场交代)列「疑似遗忘/疑似引发不满」候选清单,标注「待读者数据验证」。
- 来源:原话「先只写一个主角和2个配角一个反派,还是往更多了写」的长线面 + 专业补充。

## 六、完本与复盘(收尾 + 单书拆解的最终结算)

**这一步你在决策什么**:什么时候踩刹车开始收尾;以及拆完这本书,最终结算出什么带走。网文完本比开书难,烂尾是常态,好的完本=终极矛盾足额兑现+情感闭环+在势能耗尽前果断收手。拆书的最后一步是换位:如果我是作者,开书那天桌上必须摆什么?再把可复制套路和不可复制红利分开——套路进工具库,红利提醒自己别硬抄。这一步不做,等于白拆。

**6.1 收束期从哪开始、结构配比是什么?** ·重要·写手视角
- 问:善终的书从哪个节点开始「只收不放」(不再开新地图/新势力/新伏笔)?收束期占全书总字数比例?最终决战几章、决战后的尾声(番外/后日谈/群像交代)又占几章?
- 为什么:烂尾的第一征兆是该刹车时还在开坑;拆出刹车点位置和收束配比,就有了「什么时候开始写结局」的量化信号。
- 产出:收束期结构图(刹车点→决战→尾声的字数配比),善终书多本对比。
- 来源:专业补充(用户目标「百万字级网文」隐含完本)。

**6.2 开书时的承诺完本时都兑现了吗?** ·加分·写手视角
- 问:开书的核心承诺(身世之谜/终极反派/金手指来历)各自兑现了没有、在哪里兑现?善终书与烂尾书在「承诺兑现率」和「结局前新坑密度」上的数据差异?
- 为什么:读者对结局的评价本质是对账;善终/烂尾对照组让「怎么算写完了」有了可检查清单。
- 产出:承诺-兑现核对表 + 善终/烂尾对照数据。
- 来源:专业补充。

**6.3 这本书踩过什么坑、怎么救回来的?** ·重要·大神视角 ·†
- 问:节奏崩过的卷、被读者骂的毒点、明显烂尾的支线有哪些?作者怎么补救的,或没救回来的后果是什么?
- 为什么:成功书里的失败段落是最便宜的学费;知道大神在哪一卷也崩过、怎么救的,比只看优点更能防止重蹈覆辙。
- 产出:事故与补救案例表(位置/问题/读者反应/补救手法/效果)。**†降级**:「被读者骂/读者反应」无书评/本章说数据时,以结构指标异常段(节奏骤变/支线中断/爽点长期断供)推断候选事故点,补救手法照常从文本拆,「读者反应/效果」列标注「待读者数据验证」。
- 来源:专业补充(大神视角)。

**6.4 倒推:作者开书前的「最小开书包」是什么?** ·核心·大神+写手共识
- 问:从成书倒推,开书那天桌上必须摆着什么——主角卡+几个配角+反派第一梯队+力量体系前几级+第一卷大纲+卖点一句话?每项建议写到什么深度(证据:该项在前 N 章的实际使用情况)?哪些内容明显是写到那儿才补的?
- 为什么:这直接回答用户最原始的困惑「开新书第一天要写哪些设定、写多深」——答案必须从成功书倒推,而不是凭空规定;它是本清单第一、二节所有实证问题的最终汇总出口。
- 产出:最小开书包清单(必备项/建议深度/使用证据),汇总第一、二节的实证结论。
- 来源:原话「要写哪些设定,先写世界观还是先写人设还是先写剧情大纲…写的话要多深入」。

**6.5 这本书的成功,哪些可复制、哪些不可复制?** ·核心·**四视角共识**
- 问:把成功要素放进三栏归因表——结构性可复制(节奏曲线/钩子节律/单元循环/揭示节奏/卡点结构)、风格性难复制(文笔/梗密度/个人趣味)、环境性不可复制(题材首发红利/平台推荐/时运)——每栏列具体证据并给粗略权重?核心判据:换个人现在照这个结构写,还能不能成?
- 为什么:拆书最大的坑是把红利当套路抄——抄诡秘的克苏鲁题材学不到它的结构功力;这张表直接决定拆书系统的力气分配:第一栏做深做量化,第二栏只做风格样本存档(给 AI 当文风参照),第三栏显式标注「不可学」防止误学。
- 产出:三栏归因表(要素/证据章节/可复制性判级/权重)。
- 来源:原话「套路是什么」+ V0-D3 的执行化。

**6.6 本书的「节奏基因卡」长什么样?** ·重要·大神视角
- 问:把本书关键参数(**平台+商业模式**/爽点密度/升级间隔/单元时长/主支线比/悬念配比/首爽字数)汇总成一张卡?
- 为什么:这是单书拆解的参数化总结算,也是跨书对比(8.2)的标准输入;没有这张卡,单书拆解的结论无法参与跨书归纳——卡头的「平台+商业模式」字段是 8.2 分层对比的依据,不可缺省。
- 产出:节奏基因卡(单书参数汇总,含商业模式元数据字段,格式统一以支持跨书叠加)。
- 来源:原话「现有的网文,他们都是怎么写的,套路是什么」引申。

## 七、向写作 agent 交付(拆书产出的工程出口,横切所有阶段)

**这一节在决策什么**:拆书产出以什么形态交付,才能被 inkos/neuro-book 类写作管线真正消费。这是用户的终极出口——「即使有这些 agent 了,写作还是得有其他东西的」,那个「其他东西」就是这里定义的输入文件。这也是评审标尺里最工程化的一把尺:**任何拆书产出都应能回答「哪个 agent、在管线哪一步、以什么格式吃掉它」**,对不上消费点的产出默认降优先级。百万字 agent 写作不崩的本质,是把人类作者的隐性记忆与手感外化成可加载的结构化文件——而这些文件的 schema 和实证参数只能从成功作品里拆出来。

**7.1 产出物×消费点的映射表是什么?** ·核心·工程视角
- 问:每类拆书产出(人设卡/世界书条目/套路状态机/节奏参数/伏笔账本/校验规则/**雷点负向规则**/范文片段)分别被写作管线的哪个环节消费、目标文件格式是什么(JSON schema/YAML 世界书/Markdown 模板)?
- 为什么:这是 V0-C1「除了 agent 还需要给它什么」的完整工程答案,也是整个拆书系统的出口规格;没有这张映射表,产出的形态设计就没有验收标准。
- 产出:产出物×消费点映射表 + 每类产出的文件格式规范(带示例文件)。
- 来源:原话「即使有这些agent了,我觉得写作还是得有其他东西的」。

**7.2 每类产出是否遵守「schema+实例」双层交付?** ·核心·工程视角
- 问:可复用的空白模板(跨书通用)与样本书填充实例(示范怎么填)是否成对出现?
- 为什么:只有实例无法迁移到自己的新书,只有 schema 不知道怎么填;双层交付同时服务「学习」和「直接复用」,且实例正是给用户挑毛病的实物——匹配用户「只能看到哪里不合适才能提出问题」的工作模式。
- 产出:双层交付格式约定(每类产出一对:空白模板+填充实例)。
- 来源:专业补充(呼应原话「我只能是看到哪里感觉不合适提出问题」)。

**7.3 单章生成的「最小上下文包」应装什么?** ·核心·工程视角
- 问:写好第 N 章实际需要引用前文的哪些信息?样本书一章的内容平均回指多远(近 3 章/近 30 章/全书级设定)?据此,单章上下文最小包应含哪几类条目(活跃人物卡/未回收伏笔/当前目标/上章末状态),每类条目的保鲜期多长?
- 为什么:这是长上下文限制的工程解——与其塞全文,不如按实证回指距离构造检索包;回指距离分布只能从真书标注量出来,任何 agent 框架都给不了。
- 产出:回指距离分布图 + 单章上下文包条目清单模板(带保鲜期)。
- 来源:原话「受限于上下文注意力等各项问题」。

**7.4 「节奏」用什么可测指标定义?** ·核心·工程视角
- 问:节奏用哪几个章节级可测指标定义(冲突密度/新信息引入量/爽点兑现密度/情绪极性/悬念张力)?按这套指标量出的样本书全书曲线什么样?
- 为什么:没有可测定义,节奏控制器无法工作,拆书的节奏产出也无法验收——「节奏好」不可判定,「第 40-60 章冲突密度低于基线」可判定;指标定义是第四节所有节奏问题的前置。
- 产出:节奏指标定义文档(每个指标的测量方法)+ 样本书章节级多指标曲线。
- 来源:原话「剧情节奏怎么设计」的工程化。

**7.5 品类套路能否编码为「阶段状态机」?** ·核心·工程视角
- 问:套路(如废柴流=受辱→获金手指→首次打脸→晋升→更大舞台循环)能否编码为状态机——每阶段的入口条件、出口条件、必备事件?不同书在同一状态机上的变体差异在哪?
- 为什么:套路模板要被大纲 agent 消费,最合适的形态是状态机而不是散文总结——agent 据此判断「当前剧情处于哪个阶段、下一步该发生什么」;变体对比防止写成千篇一律。
- 产出:套路状态机(节点=阶段,边=转换条件)+ 多书变体对比表。
- 来源:原话「他们都是怎么写的,套路是什么」的工程化。

**7.6 可参数化与不可参数化的产出怎么分离?** ·重要·工程+编辑共识
- 问:结构类产出(节奏/套路/账本)编码为参数与规则;文笔类(描写/对话质感)无法参数化——是否改为输出「分场景类型的原文范文片段库」供生成 agent 做 few-shot 风格参照?
- 为什么:把文笔硬塞进参数是常见的拆书系统设计错误;工程上文笔的唯一可消费形态是带场景标签的高质量范文片段。明确这条分界,避免系统在「量化文笔」上浪费开发量,也与 6.5 的「风格性难复制只存档」一致。
- 产出:产出二分类规范 + 范文片段库格式(场景类型标签+片段+出处)。
- 来源:引申(V0-D3 的执行化)。

## 八、跨书学习(拆多本之后才能回答的问题)

**这一节在决策什么**:哪些结论能进模板当约束、哪些只是单书特例。单书结论只是样本量为 1 的观察;用户要的「他们都是怎么写的」本质是跨书归纳。显式区分已验证/待验证,是拆书系统从「读书笔记工具」升级为「方法论引擎」的分水岭。

**8.1 哪些结论跨书验证过、可进「已验证套路库」?** ·核心·**四视角共识**
- 问:哪些结构结论在 N≥3 本成功书中重复得到验证、可进入已验证套路库?品类「必给预期」清单的交集怎么构建(N 本书里出现 M 本的元素排序)?待验证候选晋升为已验证的门槛是什么?套路库如何按品类分层维护?
- 为什么:这是最终喂给写作 agent 的知识库形态;把单书特例当品类规律会系统性带偏生成。交集清单建成后,即按 1.1 过渡方案的约定取代先验清单。
- 产出:分级套路库(条目/支持书目数/品类适用范围/置信级)+ 晋升规则 + 品类必备元素交集统计。
- 来源:原话「学习现有的网文,他们都是怎么写的,套路是什么」+ V0-D1/D2 的执行化。

**8.2 哪些参数是品类共性、哪些是个人风格?** ·核心·大神视角
- 问:把多本书的节奏基因卡(6.6)并排对比:爽点密度/升级间隔/单元时长/主支线比/悬念配比等参数,哪些跨书收敛(品类共性)、哪些各书发散(个人风格)?**硬性规定:跨书归纳必须按样本书元数据的「商业模式」(付费/免费)分层进行,不得混合**——两种模式的卡点位置、钩密度、开篇节奏是两套体系,混层会得出错误的「品类共性区间」。
- 为什么:单本书的参数可能是特例,两本以上对比才能分离品类规律和个人风格——这直接决定哪些参数能进开书模板当硬约束;而分层是这一步的前置纪律,分错层比不分析更有害。
- 产出:跨书参数对比表(**按商业模式分层**;共性参数带区间,个性参数标注为可选风格)。
- 来源:原话「套路是什么」引申。

**8.3 单书结论的置信度怎么标注?** ·重要·工程视角
- 问:哪些参数必须拆够 N 本才可信?单书拆出的数字如何标注「样本量=1,仅供参考」?
- 为什么:管线把拆书参数当硬约束用,置信度字段让下游知道哪些能当约束、哪些只能当参考,也为跨书学习预留数据结构。
- 产出:参数置信度字段规范(样本量/方差/适用品类范围)。
- 来源:专业补充。

**8.4 同套路的扑街书差在哪个环节?** ·重要·编辑视角 ·†
- 问:同品类同套路但扑街的对照书,与成功书的差异出现在哪个具体环节(首爽点太晚/卡点错位/悬念账本失控)?拆书系统要不要引入失败样本作对照组?
- 为什么:只拆成功书会得到大量「成功书有 X」的假因果——扑街书往往也有 X;真正的成功因子必须是成功书有而失败书没有的差异项。这决定选书策略,不只是拆法。
- 产出:成功/扑街配对对比表(同套路两本书的结构执行差异)。**†降级**:无留存漏斗数据时,只做结构执行差异对比(两书在各北极星参数上的落差),「该差异导致扑街」的因果归因标注「待读者数据验证」。
- 来源:专业补充。

**8.5 口碑崩盘前有什么可检测的异常信号?** ·加分·工程视角 ·†
- 问:口碑由盛转衰的书,下滑区间前后的节奏指标/设定引入/战力曲线出现了什么异常?这些信号能否做成写作管线的预警规则?
- 为什么:崩点信号是校验器和节奏控制器最有价值的报警规则来源;需要负样本和口碑数据配合,实现成本较高。

## 对系统现状的映射(按 V1 框架重写,2026-07-26 快照)

**现有产出物服务了谁**:

- **抽取层(人物/事件/时间线/事实状态)= 原料层**。它不直接回答任何一条北极星问题,但它是几乎所有「可定位、可计数」答案的前提:人物表是 2.1-2.5、5.6 的原料;事件/时间线是 4.1、4.6、5.1 各类曲线定位的坐标系;事实状态是 5.2/5.4 账本的雏形。其职责仍然是「拆得对」(验收单 A1-A7),抽取不准,上面全部作废——**抽取准确是底线**。
- **深层拆解(伏笔/冲突/节奏)= 从原料到答案的第一段桥**,最贴近 4.6-4.10 与 5.3。但按 V1 标尺检验,现有形态偏描述性:缺逐章标注序列、字数轴曲线、分布统计这些「可计数」形态,也缺「结论附原文摘句」的证据形态(总原则 1),更没有一条产出声明过自己的 agent 消费点(7.1)。

**最大缺口(按新框架排序)**:

1. **两个结算出口完全缺失**:第六节的「最小开书包倒推」(6.4)和「可复制/不可复制归因」(6.5)是所有拆解的最终结算,目前没有任何对应产出——不做这两件事,前面拆得再细也没有沉淀成用户能带走的东西。
2. **开书前决策层(第一节)无产出**:卖点一句话、金手指规格卡、品类预期核对、雷点禁忌清单,全部空白。
3. **agent 交付层(第七节)无规范**:没有产出物×消费点映射,没有 schema+实例双层约定;现有深层拆解即使内容对,形态上也无法被 inkos/neuro-book 消费。
4. **参数化程度不足**:V1 的多数核心问题要求曲线/分布/间隔统计(首爽字数、爽点密度、悬置期分布、战力差曲线),现有管线未产出任何一条字数轴上的曲线。
5. **跨书层(第八节)是远期**:单书拆解未成熟前不启动,但节奏基因卡(6.6)的统一格式(含平台+商业模式元数据字段)应尽早定,否则每本书拆完的参数无法叠加、也无法按商业模式分层。

**评审用法重申**:任何新产出/界面/功能,先问三件事——对上哪条问题编号(以核心级速查表为主尺,仅对上重要/加分的降半级)?答案是否可定位可计数、关键结论带没带原文摘句?能否说出 agent 消费点或结算出口?三问都答不上的,降优先级。标 † 的问题按「结构侧证据+候选风险点+待读者数据验证」的降级形态验收,不以「答不出完整结论」为由豁免。用户的设计模式是「只能对实物挑毛病」,所以系统侧应主动把候选答案形态(模板+样本书填充实例)做出来给用户筛,而非等需求。
