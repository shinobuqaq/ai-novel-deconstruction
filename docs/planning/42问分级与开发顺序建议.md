# 42问分级与开发顺序建议

## 给用户的说明

这份文档把42问按**你开书的真实顺序**和**必需程度**重新分组。
看完后你可以直接说：

## P0 级：不知道这些就开不了书（建议12问）

### 第一组：开书前必须想清楚的（4问）
- **1.4 卖点能否一句话概括、第几章第一次兑现？**
  - 这是你整本书的"钩子"，不知道这个等于没想清楚要写什么
- **1.5 金手指五要素规格；限制条款被真实触发过几次？**
  - 爽文核心，能力边界不清楚后面必崩
- **2.2 主角双层欲望与最小完整集各在第几章立住？**
  - 人物动机，这个立不住读者不care主角
- **2.10 力量体系阶梯够不够长？硬规则与代价是什么？**
  - 战力膨胀的防线，不想清楚后面会自己打脸

### 第二组：黄金三章怎么写（4问）
- **3.1 开场第一幕什么类型，主角怎么登场？**
  - 第一章写不好，后面再好也没人看
- **3.2 前三章逐章任务与信息装载顺序是什么？**
  - 三章要交代什么、顺序怎么排
- **3.3 第一个爽点在第几章第几段、铺垫距离多少字？**
  - 爽点太晚读者跑了
- **3.4 前三章章末钩是什么、多快兑现？**
  - 追读的命脉

### 第三组：连载节奏基本盘（4问）
- **4.5 爽点类型怎么配比？重复时怎么对抗边际递减？**
  - 连载日更必须知道的
- **4.6 爽点密度曲线什么形状、分阶段怎么变？**
  - 控节奏的基础
- **4.9 章末钩类型配比与强弱节律是什么？**
  - 追订生死线
- **4.10 悬念的埋设、兑现和存量账本怎么管理？**
  - 不懂这个后期会乱

## P1 级：开书能开，但这些能让质量上台阶（建议12问）

### 主要人物配置（3问）
- **2.1 前3/10/30章实际登场并起作用的人物各几个？**
  - 知道引入节奏，避免一开始人物爆炸
- **2.3 常驻配角按什么功能编制，有无重叠或空缺？**
  - 配角班子怎么配
- **2.4 反派梯队怎么供压？反派有没有自己的事业？**
  - 反派不立体就是工具人

### 品类与差异化（3问）
- **1.1 品类"必给预期"清单；本书逐条兑现在第几章、怎么兑现？**
  - 知道读者期待什么
- **1.2 品类雷点禁忌清单；本书哪里擦边、怎么化解？**
  - 避免踩雷
- **1.3 差异化落在哪一层，动没动品类核心预期？**
  - 创新的边界

### 结构与单元（3问）
- **4.1 有没有可复用的事件单元模板？复用了几次？**
  - 套路的模块化
- **4.2 卷末大高潮的收束链与波次结构怎么运作？**
  - 高潮怎么写
- **4.12 单章内部的微结构模板是什么？**
  - 单章怎么写才不水

### 长线管理（3问）
- **5.1 战力曲线全景与防膨胀手法是什么？**
  - 战力体系怎么控
- **5.2 规则与代价被真实执行过吗？硬软怎么区分？**
  - 规则一致性
- **5.3 长线伏笔怎么埋、怎么保温、怎么引爆？**
  - 长篇的伏笔技巧
