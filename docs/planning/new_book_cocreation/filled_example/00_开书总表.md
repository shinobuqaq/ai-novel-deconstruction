## 品类承诺与禁区

### 必须兑现

1. 能力规则清楚，主角靠理解规则而不是临时开新能力解决困局。
2. 每次借用都产生可追踪的代价，债务会真实影响后续剧情。
3. 城市异象逐级扩大，但每个事件都推进主角父亲失踪的长线谜团。
4. 主角实力和身份同步成长：普通目击者 → 临时协作者 → 能独立处理债务事件的人。

### 明确规避

1. 不用“系统突然送新功能”解决死局。
2. 不让官方组织集体降智给主角让路。
3. 不把代价写成只在介绍里存在、实际从不咬人的装饰。
4. 不用无意义隐瞒拖延队友沟通；隐瞒必须有可说明的利益或风险。

## 持续剧情发动机

### 核心机制：未来借据

主角可以借用“七天内的自己有现实可能掌握或完成的能力成果”，每次最多持续十分钟。借用结束后生成一笔具体债务，要求他在期限内真正完成相应训练、行动或交换。

### 持续产剧情方式

- **短线**：借什么能力解决眼前异象，怎样在规则限制内使用。
- **中线**：怎样偿还旧债，同时处理因偿债引发的新冲突。
- **长线**：谁建立了借据规则，父亲为何留下已经逾期七年的借据。

### 限制

1. 不能借到未来自己不可能获得的能力。
2. 同时最多背负三笔债务。
3. 逾期不是扣除抽象数值，而是在最不利时强制收走等价的时间、记忆或行动机会。
4. 每次借用都会让能追踪“债痕”的组织更容易发现主角。
