# 《我向明天借十分钟》人物与关系

> 虚构测试样本。只建立第一卷会实际起作用的人物。

## 主角：林砚

| 字段 | 当前结果 |
|---|---|
| 叙事功能 | 规则解题者和债务承担者；用他的每次选择检验“得到力量是否值得付出代价”。 |
| 性别呈现与称谓 | 男性，使用“他”。 |
| 人生阶段 | 23 岁，刚离开学校不久，在临江市做夜间紧急跑腿。 |
| 外貌识别锚点 | 总戴一只停在 23:47 的旧机械表；紧张时会反复拨动已经卡死的表冠。 |
| 当前外在目标 | 查清七号旧街反复出现的火灾异象，并找到失踪委托人的下落。 |
| 深层欲望 | 证明“只要再快一点就能救下所有人”，以逃避自己曾经迟到一步造成的内疚。 |
| 行为底线 | 不把无关者当偿债工具；即使会失去能力，也不接受用陌生人的记忆抵债。 |
| 内在矛盾 | 极度讨厌欠人，却只能靠不断欠未来的自己来救人。 |
| 压力下的行为与取舍 | 先找最低代价的规则漏洞；若必须二选一，优先救眼前能确认的人，而不是追逐不确定的长线答案。 |
| 第一卷变化 | 从“所有债都必须自己背”转变为愿意与可信的人共享信息和风险。 |
| 首次登场展示 | 为抢在午夜前送达一份无人敢接的急件，进入所有钟表都停在 23:47 的七号旧街。 |

## 核心配角：许照

| 字段 | 当前结果 |
|---|---|
| 叙事功能 | 提供官方规则和限制，也是对主角“先救人再补手续”的制衡者。 |
| 性别呈现与称谓 | 女性，使用“她”。 |
| 人生阶段 | 26 岁，临江市异常应对处调查员。 |
| 外貌识别锚点 | 记录现场时只用红色铅笔；每发现一条未验证信息就立刻画叉。 |
| 当前目标 | 在异象扩散前封锁七号旧街，并找到内部泄露封锁路线的人。 |
| 行为底线 | 不用未经验证的猜测指挥他人冒险。 |
| 内在矛盾 | 相信程序能减少牺牲，却曾因等待完整证据错过救援窗口。 |
| 压力下的行为与取舍 | 先控制变量和人员；证据证明旧方案失效后会迅速改令，不为面子坚持。 |
| 第一卷变化 | 从把林砚视为危险变量，转为允许他参与制定方案。 |

## 第一梯队反派：周烬

| 字段 | 当前结果 |
|---|---|
| 叙事功能 | 制造七号旧街循环的人，也是“为了救一个人能否让整条街反复付账”的反面答案。 |
| 性别呈现与称谓 | 男性，使用“他”。 |
| 人生阶段 | 42 岁，前消防调查员。 |
| 外貌识别锚点 | 身上始终带着一截被烧熔的门锁，谈话时会下意识确认出口。 |
| 自己的目标 | 让七年前死在火灾中的女儿在某一次循环中真正走出旧街。 |
| 与主角的结构性冲突 | 两人都想弥补“迟到一步”，但周烬接受让其他人重复死亡作为交换，林砚不接受。 |
| 可调用资源 | 熟悉旧街火场结构；掌握一份能把他人未来转成偿债时间的非法契约。 |
| 行为底线 | 不亲手伤害循环中的女儿；除此之外愿意牺牲任何人。 |
| 压力下的行为与取舍 | 只要女儿有一线成功可能，就会继续加码，不承认已经投入的牺牲没有意义。 |
| 第一卷结局 | 失去对循环的控制，但留下证据证明林砚父亲曾主动签署同类契约。 |

## 轻量配角：杜野

| 字段 | 当前结果 |
|---|---|
| 叙事功能 | 提供交通、设备维修和普通人视角，提醒主角异象之外仍有现实生活。 |
| 性别呈现与称谓 | 男性，使用“他”。 |
| 人生阶段 | 24 岁，林砚的合租室友和摩托维修工。 |
| 记忆点 | 修任何东西前都先拍照，口头理由是“免得修完没人信它原来有多烂”。 |
| 第一卷任务 | 通过维修记录发现林砚的机械表每天都会凭空多出十分钟磨损。 |

## 关系与冲突

| 双方 | 表面关系 | 双方各自想得到什么 | 当前张力 | 第一卷变化 |
|---|---|---|---|---|
| 林砚—许照 | 被调查者与调查员 | 林砚要信息和进入现场的资格；许照要可控的能力样本 | 救援速度与程序安全冲突 | 从互相隐瞒变为有限共享债务记录 |
| 林砚—周烬 | 阻止者与事件制造者 | 林砚要终止循环；周烬要借林砚的能力完成最后一次改写 | 两人有相同创伤、相反底线 | 林砚拒绝成为周烬的下一份抵押物 |
| 林砚—杜野 | 朋友与合租室友 | 林砚想保护普通生活；杜野想知道朋友为何不断失去记忆 | 保护性隐瞒逐渐破坏信任 | 杜野知道部分真相并主动留下外部记录 |
