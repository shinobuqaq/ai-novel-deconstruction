# 3.1 开场第一幕什么类型，主角怎么登场？

> **状态**：✅ 已完成（基于《龙族》75万字样本）

---

## 为什么重要

开头100字决定读者是否继续。第一幕必须抓住注意力并建立代入感，主角登场太晚或开场和主线无关会导致读者流失。

**开场类型**：悬念异象 + 梦境开局

**关键数据**：

- 手法：先展示白帝城毁灭梦境（悬念），再切回平凡高三生（反差）

| 第1章:12段 | "路明非梦见了白帝城的毁灭..." | 主角登场 |

## 通用方法

### 三大开局类型

**1. 悬念开局**：展示异象/谜团 → 激发好奇
- 适用：玄幻、仙侠、悬疑
- 结构：异象展示(200-500字) → 切回主角日常 → 埋下连接

**2. 动作开局**：直接战斗/危机 → 刺激感官
- 适用：爽文、游戏竞技
- 结构：开头即动作 → 边打边揭示人物 → 留悬念

**3. 反差开局**：平凡vs非凡对比 → 制造期待
- 适用：都市异能、系统流
- 结构：平凡日常 → 非日常元素出现 → 主角被迫卷入

### 主角登场铁律

- ✅ 最晚第15段必须出现（约500字内）
- ✅ 登场时要有行动，不只是描述外貌
- ❌ 禁忌：世界观说明书开场、环境描写超过3段

## 实操工具

### 自检清单

- [ ] 我选择悬念、动作还是反差开局？
- [ ] 主角在第几段登场？（建议5-15段）
- [ ] 主角首次行动能体现性格吗？
- [ ] 开场事件和主线有关联吗？
- [ ] 读者看完前100字会想继续吗？

### 常见错误

1. **天地玄黄式开场**：前500字都是世界观设定 → 用事件展示规则
2. **主角登场太晚**：超过第20段才出现 → 前3段必须有人
3. **开场和主线无关**：第1章骗流量第2章才进主线 → 开场必须是主线起点
4. **悬念太空泛**："命运齿轮转动"等空话 → 要具体事件和画面

### 可套模板：梦境/异象开局

```
第1-3段：具体异象（不要"一道光"，要有画面）
  ↓
第4-8段：切回主角日常（建立代入感）
  ↓  
第9-15段：主角对异象的反应（困惑/不安）
  ↓
第一章结尾：悬念钩子（异象元素在现实出现）
```

**检查点**：异象够震撼？主角够接地气？连接够自然？

### 数值参考

| 指标 | 建议范围 | 说明 |
|------|---------|------|
| 主角登场位置 | 第5-15段 | 悬念型可推后，爽文型要提前 |
| 主角登场字数 | 150-500字 | 超过500字读者可能流失 |
| 第一幕总长 | 500-2000字 | 第1章的前1/3到1/2 |
